## Installation
- Download the release version
- Extract anywhere you wish to keep it
- Run Aurora NAT Updater.exe
- Past your Aurora directory if required by the program
- Press Enter to close it
- Reload Sectorfile

### Note: 
This only works with the **CA - Gander/Shanwick OCC (Latest)** sectorfile, it will not work with the GB one.
This is not intended for real world navigation.
